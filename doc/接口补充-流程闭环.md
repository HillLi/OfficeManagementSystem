# 高校办公管理系统接口补充：流程闭环

**日期**：2026-05-22  
**范围**：附件、审计日志、通知提醒、流程实例、业务闭环接口。

## 通用流程能力

| 方法 | 地址 | 说明 |
|------|------|------|
| GET | `/api/workflow/tasks?onlyMine=true` | 查询当前登录人的待办任务 |
| GET | `/api/workflow/instances` | 查询当前登录人可见的流程实例 |
| GET | `/api/workflow/notifications?unreadOnly=false` | 查询站内通知 |
| POST | `/api/workflow/notifications/{id}/read` | 将通知标记为已读 |
| POST | `/api/workflow/attachments` | 新增业务附件 |
| GET | `/api/workflow/attachments?bizType=document&bizId=1001` | 查询业务附件 |
| GET | `/api/workflow/audit-logs?bizType=document&bizId=1001` | 查询操作审计日志，仅管理员可访问 |

附件请求示例：

```json
{
  "bizType": "document",
  "bizId": 1001,
  "fileName": "draft.pdf",
  "fileUrl": "/uploads/draft.pdf",
  "secrecyLevel": "内部"
}
```

## 业务闭环接口

| 业务 | 方法 | 地址 | 说明 |
|------|------|------|------|
| 公文 | POST | `/api/documents/{id}/archive` | 审批通过后归档公文 |
| 会议 | POST | `/api/meetings/{id}/minutes` | 审批通过后登记签到人数、会议纪要并归档 |
| 差旅 | POST | `/api/travels/{id}/reimburse` | 审批通过后提交实际报销金额和票据附件，进入财务复核 |
| 请示报告 | POST | `/api/reports/{id}/reply` | 审批通过后填写批复意见并归档 |

会议纪要请求示例：

```json
{
  "minutes": "会议完成系统试运行安排确认。",
  "signInCount": 58
}
```

差旅报销请求示例：

```json
{
  "actualExpense": 2450,
  "receiptUrl": "/uploads/travel-1001.pdf"
}
```

请示报告批复请求示例：

```json
{
  "reply": "同意按流程办理。"
}
```

## 权限说明

- 所有 `/api/workflow/**` 接口均需要登录 token。
- `/api/workflow/audit-logs` 仅系统管理员可访问，避免普通用户读取全量审计数据。
- `/api/workflow/instances` 按当前登录用户可见范围过滤：管理员、党办校办、校级领导可查看较宽范围；申请人、经办角色只能查看与自己有关的流程。
