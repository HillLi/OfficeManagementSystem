# 高校办公管理系统接口补充：权限与业务闭环

**更新日期**：2026-05-25
**范围**：会话失效、附件与审计、通知提醒、流程实例、公文签收、印章移交、会议纪要、差旅报销、统计导出。

## 1. 会话与通用流程

| 方法 | 地址 | 说明 |
|------|------|------|
| POST | `/api/auth/logout` | 注销当前 Bearer token；该 token 后续请求返回 `401` |
| GET | `/api/workflow/tasks?onlyMine=true` | 查询当前登录人的待办任务 |
| GET | `/api/workflow/instances` | 查询当前登录人可见的流程实例 |
| GET | `/api/workflow/notifications?unreadOnly=false` | 查询站内通知 |
| POST | `/api/workflow/notifications/{id}/read` | 标记通知为已读 |
| POST | `/api/workflow/attachments` | 新增业务附件 |
| GET | `/api/workflow/attachments?bizType=document&bizId=1001` | 查询当前用户可访问业务的附件 |
| GET | `/api/workflow/audit-logs?bizType=document&bizId=1001` | 查询操作审计日志，仅管理角色可访问 |

附件请求示例：

```json
{
  "bizType": "document",
  "bizId": 1001,
  "fileName": "draft.pdf",
  "fileUrl": "/uploads/draft.pdf",
  "secrecyLevel": "内部"
}
```

## 2. 公文分发与签收

| 方法 | 地址 | 说明 |
|------|------|------|
| POST | `/api/documents/{id}/submit` | 申请人提交草稿或退回后的公文 |
| POST | `/api/documents/{id}/archive` | 审批通过后由党办校办或管理员归档 |
| POST | `/api/documents/{id}/distributions` | 创建接收人或部门分发记录 |
| GET | `/api/documents/{id}/distributions` | 查询可见公文的分发与签收记录 |
| POST | `/api/documents/{id}/distributions/{distributionId}/receipt` | 接收人办理签收 |
| POST | `/api/documents/{id}/distributions/{distributionId}/remind` | 党办校办或管理员发起催办提醒 |
| POST | `/api/documents/{id}/ai-review` | 发起 AI 审查；涉密密级直接阻断并审计 |

权限规则：

- 公文申请人可维护和提交自己的草稿；审批人按流程处理待办。
- `office_admin` 与 `admin` 可归档、分发并催办已审批公文；接收人可办理本人签收。
- 密级为 `内部`、`秘密`、`机密`、`绝密` 及历史导入数据中的 `internal`、`secret`、`confidential`、`top_secret` 等值时，不得调用外部 AI 审查。

分发请求示例：

```json
{
  "receiverId": 2,
  "deptId": 4
}
```

## 3. 印章使用与移交

| 方法 | 地址 | 说明 |
|------|------|------|
| POST | `/api/seals/applications/{id}/used?keeperId=8` | 印章管理员登记已用印 |
| POST | `/api/seals/applications/{id}/returned?keeperId=8` | 印章管理员登记归还 |
| POST | `/api/seals/transfers` | 新建印章移交记录 |
| GET | `/api/seals/transfers` | 查询印章移交记录 |

外带申请必须包含 `takeOutReason`、`takeOutLocation`、`supervisorId` 与 `expectedReturnTime`，以便落实监督使用和按时归还。

## 4. 会议、活动与差旅闭环

| 业务 | 方法 | 地址 | 说明 |
|------|------|------|------|
| 会议 | POST | `/api/meetings/{id}/minutes` | 审批通过后登记签到人数和会议纪要并归档 |
| 差旅 | POST | `/api/travels/{id}/reimburse` | 审批通过后提交实际报销金额、票据附件和超标准说明，进入财务复核 |
| 请示报告 | POST | `/api/reports/{id}/reply` | 审批通过后填写批复意见并归档 |

会议申请支持住宿费、伙食费、场地费和其他费用的分项录入。大型活动申请还须提交风险评估、安全方案和应急预案材料，并满足至少提前 15 个工作日提出申请的校验规则。

差旅报销请求示例：

```json
{
  "actualExpense": 2450,
  "receiptUrl": "/uploads/travel-1001.pdf",
  "overLimitReason": "因临时调整交通方式，已补充审批说明。"
}
```

## 5. 数据统计与导出

| 方法 | 地址 | 说明 |
|------|------|------|
| GET | `/api/statistics` | 按当前用户可见业务范围返回统计摘要 |
| GET | `/api/statistics/export` | 按同一权限范围导出 UTF-8 CSV 报表 |

统计接口仅聚合用户可见范围内的数量和金额，不返回涉密正文、附件内容或越权业务详情。

## 6. 权限与审计约束

- 所有业务与工作流接口均需要有效登录 token；注销和超时后的 token 不得继续访问资源。
- 附件、流程实例、分发记录和统计数据均按业务可见范围过滤。
- 归档、分发、催办、移交、报销提交以及 AI 涉密阻断等关键动作写入审计或流程记录，便于追溯。
