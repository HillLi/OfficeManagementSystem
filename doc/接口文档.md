# 高校办公管理系统接口文档

> 2026-05-26 更新：用印申请改为草稿后上传真实材料再提交审批，并新增材料维护接口；请结合《接口补充-流程闭环.md》作为当前完整接口说明。

接口统一返回：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

## 登录与用户

| 方法 | 地址 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| GET | `/api/auth/users` | 查询演示用户 |

登录请求：

```json
{
  "username": "user",
  "password": "123456"
}
```

| GET | `/api/documents` | 查询公文列表 |

```json
  "applicantId": 2

```

## 印章管理

| 方法 | 地址 | 说明 |
|------|------|------|
| GET | `/api/seals` | 查询印章台账 |
| GET | `/api/seals/applications` | 查询用印申请 |
| POST | `/api/seals/applications` | 保存用印申请草稿，响应包含 `sealName` 与 `materialCount` |
| POST | `/api/seals/applications/{id}/submit` | 草稿已具备至少一份有效材料后提交审批 |
| POST | `/api/seals/applications/{id}/used?keeperId=8` | 用印登记 |
| POST | `/api/seals/applications/{id}/returned?keeperId=8` | 归还确认 |

用印申请请求：

```json
{
  "sealId": 1,
  "applicantId": 2,
  "purpose": "系统试运行通知材料用印",
  "copies": 2,
  "takeOut": false,
  "matterLevel": "常规事项"
}
```

保存草稿后，调用 `/api/workflow/attachments/upload` 上传真实材料文件；不得通过 `materialUrl` 跳过材料校验。
