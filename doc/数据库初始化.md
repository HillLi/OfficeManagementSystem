# MySQL 初始化与启动说明

项目已经支持 MySQL 持久化。默认 `backend/src/main/resources/application.properties` 使用内存模式；使用 MySQL 时启用 `mysql` profile。

## 1. 初始化数据库

在项目根目录执行：

```powershell
cd backend
powershell -ExecutionPolicy Bypass -File .\scripts\init-mysql.ps1 -User root -Password 你的MySQL密码
```

本机默认 MySQL 客户端路径：

```text
D:\dev\mysql8\mysql-8.0.39-winx64\bin\mysql.exe
```

如客户端路径不同：

```powershell
cd backend
powershell -ExecutionPolicy Bypass -File .\scripts\init-mysql.ps1 `
  -MysqlBin D:\dev\mysql8\mysql-8.0.39-winx64\bin\mysql.exe `
  -User root `
  -Password 123456
```

脚本会依次执行：

- `backend/sql/schema.sql`
- `backend/sql/data.sql`

创建数据库：

```text
office_management_system
```

## 2. 修改连接配置

配置文件：

```text
backend/src/main/resources/application-mysql.properties
```

默认配置：

```properties
oms.repository=mysql
spring.datasource.url=jdbc:mysql://localhost:3306/office_management_system?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
spring.datasource.username=root
spring.datasource.password=123456
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
```

如果你的 MySQL 密码不是 `123456`，请修改 `spring.datasource.password`。

## 3. 使用 MySQL 启动后端

```powershell
cd backend
D:\dev\maven\apache-maven-3.9.14\bin\mvn.cmd spring-boot:run -Dspring-boot.run.profiles=mysql
```

启动后，公文、用印、会议、差旅、请示报告和审批记录会写入 MySQL，并在后端重启时从 MySQL 回读。
