# 高校办公管理系统修复复测报告（2026-05-26）

## 1. 修复范围与结论

本次修复针对印章管理中的两个实际缺口：用印办理记录无法明确显示使用的印章，以及用印材料仅显示地址、缺少真实文件管理能力。

结论：当前实现已支持显示印章真实名称和有效材料数量，并完成用印材料真实上传、下载、修改、逻辑删除、审计留痕、提交约束及 MySQL 持久化闭环。普通申请人、管理角色和无关人员的访问边界已纳入自动化测试。

## 2. 已实现内容

| 范围 | 实现结果 |
|------|----------|
| 办理记录展示 | 列表返回并展示 `sealName` 与 `materialCount`，不再以文件路径或数字 ID 代替印章信息 |
| 申请流程 | 新申请保存为 `draft`；必须上传至少一份有效材料后，才允许提交进入审批 |
| 文件管理 | 支持 PDF、DOC、DOCX、JPG、JPEG、PNG 文件上传，单文件上限 20 MB；支持下载、名称/密级修改 |
| 删除与审计 | 删除采用逻辑删除，保存删除人、删除时间和删除原因；删除后不可下载；操作进入审计日志 |
| 权限控制 | 草稿申请人可上传、修改、删除；提交后申请人不可删除；管理角色可核查删除留痕；无关人员不可下载 |
| MySQL 持久化 | `sys_attachment` 增加原始名称、存储路径、大小、类型及删除留痕字段，并支持重复升级 |
| 前端体验 | 新增材料管理对话框、上传和 CRUD 操作；移动端页头与导航布局完成适配 |
